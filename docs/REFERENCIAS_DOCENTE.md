# Fuentes y aclaraciones del material docente

- Evaluación Sumativa U1 - Desarrollo Backend, pp. 3-5: implementación local de una API REST, ORM, migración, validaciones y comparación de rendimiento; apartado explícito de alcance excluido.
- Rúbrica de Evaluación U1, pp. 1-2: nueve indicadores y escala máxima de 100 puntos.
- Ficha VcM Hielos del Maipo, pp. 1-2: antecedentes aportados por la empresa sobre organización y registros. No se incluyen datos de contacto personales en el prototipo.
- Cuaderno de Ejercitación U1, pp. 8-9: actividad sobre seguridad y escalabilidad de una API.
- Sesión práctica S3: API REST con framework PHP, buenas prácticas de seguridad, rendimiento y escalabilidad.
- Documentación oficial Laravel 12 (consulta 27-10-2026): https://laravel.com/docs/12.x/installation y https://laravel.com/docs/12.x/controllers

**Observación:** la primera página de la evaluación menciona indicadores de interfaz Frontend (UI/UX), que no coinciden con las instrucciones concretas de Backend ni con su rúbrica. Para este desarrollo se priorizó el cuerpo de la evaluación de Backend y su rúbrica; conviene confirmar esta errata con el docente.
